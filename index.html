01 Manifesto

Faktor 10 is a microservices-first studio run by one person. Many small, independently deployable apps that stand alone or compound — each one its own company in spirit, sized to ship fast and prove value before it earns more investment.

The long game is to be a boutique agentic AI developer: LLM-powered interfaces, real-time inference, vector search and semantic UX applied to ordinary problems — pantries, news, habits, households.

The short game is a live URL. Semantic HTML before component libraries. Hot-swappable infrastructure over vendor lock-in. Tests where state changes, not before.

02 How I work

Five rules that decide
every trade-off.

01

Ship iteratively, spec-driven

Write the spec, cut it to the smallest honest slice, get it live. Complexity is layered onto something real — never designed into something imaginary.

02

Semantic HTML first

Start with the bare minimum markup that works for everyone. Polish, animation and component libraries arrive after the thing is usable, not instead of it.

03

Hot-swappable infrastructure

Every provider is a rental. Railway, Fly.io, Vultr, Hetzner — chosen because the exit is cheap, and the app can move in an afternoon.

04

Right-sized tooling

Solopreneur-appropriate infra beats enterprise ceremony. One language full-stack, one deploy target, one person who can hold the whole system in their head.

05

Test what changes state

Tests follow interaction and data — the moments where state moves. Coverage theatre on pure render code is waste, and waste is a design failure.
